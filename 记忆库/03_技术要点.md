# 03 技术要点

> 学到的概念、模式、API。答辩弹药库，能用自己话讲清才算掌握。

## Unity 编辑器扩展
- **EditorWindow**：`GetWindow<T>()` 打开，`OnGUI()` 每帧重绘，`MenuItem` 注册菜单入口
- **SerializedObject / SerializedProperty**：编辑器与资产数据的桥梁；`FindProperty("字段名")` → `GetArrayElementAtIndex(i)` 遍历数组 → `ApplyModifiedProperties()` 写回；`Update()` 在读取前调用
- **CreateAssetMenu**：右键菜单创建 ScriptableObject 资产
- **ScriptableObject 数据驱动**：改资产 = 改游戏（运行时读同一份资产），答辩核心论证

## Unity 程序集规则（重点，答辩可能问）
- 无 asmdef 的脚本 → 预定义程序集 `Assembly-CSharp`（运行时）/ `Assembly-CSharp-Editor`（编辑器）
- 引用方向：**预定义程序集能自动看到所有 asmdef；asmdef 之间显式引用；asmdef 不能引用预定义程序集**
- asmdef 必须显式引用包程序集（Unity.TextMeshPro、UnityEngine.UI 等）
- 编辑器文件夹（Assets/Editor）的代码编进编辑器程序集，运行时不能用

## 设计模式（项目落地）
- **单例**：SoundManager.Instance（全局音效入口）
- **观察者**：静态事件（OnPlayerDamaged/OnPlayerDeath）+ EnemyStatusBar 订阅
- **对象池**：AudioSource 池（16 个）、伤害数字池（DamagePopupManager）
- **工厂**：怪物生成器（未来工具）
- **抽象工厂**：UI 主题切换（10 月做，ThemeData + ThemeApplier）
- **状态机**：玩家 8 态（ThirdPersonController）、敌人 13 态（EnemyAI）
- **组合**：MonoBehaviour 组件化 + GetComponent 缓存（Awake/Start 中，避免 Update 里查）

## 战斗手感实现
- **连击缓冲**：INPUT_BUFFER_WINDOW=0.18s，攻击前摇时按下也缓存，窗口内自动接段
- **连击窗口**：comboWindowPercent（默认 0.55），攻击进度越过才允许下一段
- **弹反**：Physics.OverlapSphere + 弹反窗口
- **顿帧**：Time.timeScale 缩放（0.1 持续 0.05s），命中/弹反触发
- **僵直**：Poise 值累加 → 50% Stagger → 100% Knockdown

## 其他
- **WAV 格式**：RIFF 头 44 字节（RIFF+size+WAVE+fmt+data），PCM16 little-endian；BinaryWriter 默认 UTF-8
- **团结引擎 GUID**：.meta 里 base64，序列化引用里 hex，两套 ID 不可脚本映射
- **Root Motion**：OnAnimatorMove 驱动，攻击/闪避动画驱动位移，移动代码驱动（用户明确偏好）
- **FrameEvent 数据模型（动作编辑器用）**：ActionStep{伤害, 动画clip, 帧事件列表} + FrameEvent{帧, 类型(音效/伤害判定/特效), soundID}

## 2026-10-01 当前实现（优先于上面的历史原型描述）
- **严格连招窗口**：逐段局部秒数，左闭右开；窗口前旧输入丢弃，窗口内新按下只推进一段，末段不循环。旧参数回退默认窗口从65%开始，已经取消早按自动消费行为。
- **保存与重载**：窗口草稿是临时SO；保存递增revision；运行层深复制ComboStep和音效列表，保留clip资产引用。修改草稿/源资产不直接改变快照，显式重载在安全状态整体替换。
- **可编辑临时草稿**：HideAndDontSave含NotEditable，不能用于需要PropertyField编辑的SO。采用HideInHierarchy | DontSave；在OnEnable/Undo的BindDraft中同步恢复旧草稿标记，不重新创建草稿或丢弃用户改值。
- **逐段倍速**：ComboStep.playbackSpeed范围0.1～5，旧段默认1；ComboSpeedA/B分别驱动专用状态乘数，全局Animator.speed维持1。配置窗口与音效仍以原clip秒数表示，normalizedTime × 原时长返回同一时间轴；实际播放时长=原时长/倍速。编辑预览也按倍速推进。
- **Run朝向**：在Humanoid OnAnimatorIK内按指定Run的贡献权重调整bodyRotation/bodyPosition，自动对齐物理根水平朝向，再加可选微调；不直接旋转Animator Transform。主场景Base Layer已有IK Pass。移动按相机目标的稳定水平基准构造正交方向，并优先键盘方向键，减小同名手柄轴/平滑过渡带来的方向干扰。
- **内置事件**：Instantiate源clip、替换副本events，再AnimatorOverrideController.ApplyOverrides；AnimationEvent携带attackToken和来源clip，Relay拒绝过时事件。两只唯一占位片段避免下一段覆盖正处于过渡的上一段。
- **物理窗口**：Animation Event记录开关；LateUpdate在根位移后，按上帧→当前动画时间与合法hit区间交集裁剪扫掠。OverlapSphereNonAlloc补初始重叠，SphereCastNonAlloc补快速移动；HashSet<Enemy>按实体去重，墙体单独检查。
- **根位移**：移动代码计算、攻击动画deltaPosition水平倍率、跳跃重力和受击外部位移统一由OnAnimatorMove应用到Rigidbody；Animator位于子对象时Relay转发一次，避免父子重复执行。
- **状态层次**：PlayerStateGroup对Locomotion/Action/Disabled分组，共享移动/空中规则；仍用组件和轻量状态机，不引入重型状态图框架。
- **性能证据**：F8以realtimeSinceStartupAsDouble采帧，导出平均FPS、最低滚动1秒FPS、P95帧时间、逐帧CSV和设备/画质信息；标记Editor样本，PC渲染验收需真实Windows战斗样本。

## 2026-10-02 Run姿态修订
- 当前Run校正替代上述IK质心方案：动画/IK求值后在LateUpdate旋转Hips子树，以当前VRM Head.forward作为可见前向，按Run权重混合并保留额外偏角。物理根不旋转；攻击/跳跃跳过；不依赖IK Pass，父对象或Animator子对象均可使用。更换控制器/Avatar/指定clip时刷新缓存，动画每帧重写骨盆姿态。此+Z前向约定已核对momo，其他Avatar不能直接套用。
- 本机已有Codely Bridge可通过Temp/.com-unity-codely.json只读发现端口，不需修改配置或重启服务。实际握手WELCOME UNITY-TCP 1 FRAMING=1；消息使用8字节大端长度+UTF8 JSON，命令结构type/params。execute_csharp_script可执行只读诊断及临时副本采样，manage_editor/request_compile可检查引擎编译；本轮未切换用户Play状态、未保存主场景。
- 截图反馈后当前实现升级为上下身独立对齐：预先计算Hips与Head各自的目标校正，先旋转Hips，再给Spine施加faceCorrection * inverse(hipCorrection)。这样二者各自按Run权重达到前向目标，不把骨盆原有余偏留在腿部。当前momo Hips/Head的+Z基准已核对，其他Avatar需适配。采样同时验证上下身，不能继续仅测headAngle。

## 2026-10-02 动画与物理节奏修订（当前实现）
- Animator改为AnimatePhysics，与FixedUpdate转向及地面检测同一节奏；OnAnimatorMove仍是唯一位移入口，使用固定步长，刚体保持Interpolate。没有使用velocity驱动或改变工程Fixed Timestep。
- OnAnimatorMove标记新姿态；LateUpdate消费一次标记后做Run骨盆/上身补偿，未求值动画的渲染帧不再重复修改旧姿态。
- 物理动画每次根位移目标计算后调用SampleComboHitAfterRootMotion；按clip时间裁剪合法区间并实体去重，Normal模式才在LateUpdate采样。根位移目标不等于物理碰撞求解后的实际位置；现场墙体/命中/收招及顿帧需复测。

## 2026-10-03 动作正常结束与无敌窗口

- 完整非循环动作使用未取余normalizedTime>=1结束，读取过渡中的目标状态；不能用normalizedTime%1判断末尾。代码负责结束时移除控制器的普通自动收招出口，保留受击/死亡打断；缺状态/外部切走需清理回退。
- 动作持续时间和战斗无敌窗口独立：闪避1.2秒动画完整播完，不等于无敌延长到1.2秒。返回移动时同步Movement/Run与混合内部值，避免进入移动后被残留0值送回idle。所有实际位移继续经OnAnimatorMove。
