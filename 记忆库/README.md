# 记忆库（Memory Vault）

> 给 AI 的持久记忆，跨窗口、跨会话、跨电脑（跟着 git 走）。
> **新会话流程：读 AGENTS.md（自动）→ 读本文件 → 按需读下面分库。**

## 分库索引

| 文件 | 内容 | 更新频率 |
|---|---|---|
| `01_决策记录.md` | 重大决定 + 原因（为什么这么做） | 每次有决定时 |
| `02_踩坑记录.md` | 报错/问题 + 根因 + 解法 | 每次踩坑时 |
| `03_技术要点.md` | 学到的概念、模式、API 用法 | 每次学到新东西时 |
| `04_项目进度.md` | 当前状态、下一步（配合 `答辩冲刺计划.md`） | 每次收工时 |
| `05_对话日志.md` | 重要对话的压缩摘要（追加式） | 每阶段结束时 |

## 使用规则

1. **会话开始**：先读 `01`~`03` 的最新内容，再看 `04` 的当前状态
2. **回答项目问题**：优先引用记忆库已记录的事实，不要重复调查已查过的东西
3. **会话结束**：有新决策/踩坑/技术点就追加到对应文件（一句话也算）
4. **冲突处理**：记忆库与现场代码不一致时，以现场代码为准，并更新记忆库
