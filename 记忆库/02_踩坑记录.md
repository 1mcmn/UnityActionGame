# 02 踩坑记录

> 报错/问题 + 根因 + 解法。新坑追加末尾，带日期。

## 2026-08-21
- **WAV 头"损坏"虚惊**：`writer.Write("RIFF".ToCharArray())` 其实没问题（BinaryWriter 默认 UTF-8，ASCII 字符=单字节），实测头部字节完全正确；但建议换 `Encoding.ASCII.GetBytes()` 做防御性写法
- **asmdef 不能引用预定义程序集**：测试 asmdef 写 `"references": ["Assembly-CSharp"]` 会静默失败（CS0246 找不到类型）→ 给 Assets/Scripts 建 `Game.asmdef`，测试引用 `"Game"`
- **asmdef 必须显式引用包程序集**：建 asmdef 后 TMPro/ugui 报 CS0246 → `Game.asmdef` 加 `"Unity.TextMeshPro"` 和 `"UnityEngine.UI"`
- **CS0104 Object 歧义**：同时 `using System;` + `using UnityEngine;` 时裸写 `Object` 报歧义 → 全限定 `UnityEngine.Object.DestroyImmediate()`
- **团结引擎 GUID 双格式**：`.meta` 里是 base64（如 `DysZvHik...=`），预制体/场景里是 32 位 hex——无法用脚本直接映射，分析依赖时注意
- **敌人 CrossFade 全失败**：EnemyAI 引用 `Goblin_Ani_*` 约 25 个名字，Monsterctrol.controller 只有 9 个状态且一半没绑动画（m_Motion 空）；素材只有 7 个 FBX 动画（其中攻击只有 Mutant Punch 一个）→ 代码按"理想动画集"写的，需对齐素材（见 04 下一步）
- **音效找不到 atk01_swing/hit**：不是 ID 缺失（PlayerSounds.asset 有 38 条全绑好），是场景里 SoundManager 的 Libraries 挂的是空的 GameSoundData.asset → 换成 PlayerSounds.asset
- **`dsh web` 报 cannot resolve profile bundle**：profile node_modules 依赖失联（装插件时 pnpm 动过依赖树）→ `dsh plugin --profile web install`（不带包名=全部重装）
- **docker pull 报 npipe 找不到**：Docker CLI 装了但 Docker Desktop 没启动 → 启动应用 / 重启（WSL 缺失时先装 WSL）
- **`wsl --install` 报 403**：网络层拦截微软下载端点（非代理问题）→ 环境墙，暂停 OpenViking
- **`bash <(curl ...)` 报"系统找不到指定的文件"**：在 cmd 里跑 bash 命令不行，`<( )` 是 bash 语法 → 必须打开 Git Bash 里跑
- **compile_check.bat 超时**：Unity 编辑器开着时会锁编译输出文件 → 跑编译检查前先关编辑器
- **CS0108 Myobject.name 隐藏基类成员**：练习脚本字段命名问题，警告不影响运行，答辩前处理

## 2026-08-22
- **格挡后泄力动画不出现**：根因是磁盘上 3 个角色 controller（Player_NewAnimCtrl / ainbe / Anbi）都没有 `Deflect`、`Blocking`、`Knockdown`、`GetUp` 参数，代码 SetTrigger/SetBool 全部空转（Console 打 "Parameter does not exist"）。用户截图里"有"但磁盘没有 → 未保存或改错控制器，未定论
- **泄力 = 攻击倒放（纯代码实现）**：`animator.Play(攻击状态hash, 0, 收尾进度) + animator.speed = 负值` 即倒放，结束恢复 speed=1 再 CrossFade 回进入前状态。**最终倒放倍速 = 状态自身 Speed × animator.speed**（攻击状态 Speed=2，speed=-1 即 2 倍速倒放）；起始进度必须小于该状态所有 Exit Time 阈值，否则被 Exit Time 抢走；切受击/倒地/死亡前必须 CancelDeflect 恢复 speed=1
- **Unity 动画倒放**：状态 Speed 填负数即倒放（动画机方案）；负速度 + Has Exit Time 有已知 bug（speed multiplier ignores exit time），退出用代码计时器兜底更稳
- **武器资源已有**：`Assets/Imports/PurePoly/Free Fantasy RPG Weapons`（单手剑 PP_Theme_11_Sword_One-Handed_003 等 26 个 prefab，自带 MeshCollider），玩家/怪物武器不用外部找

## 2026-10-01
- **实际动画名不是状态长名**：玩家控制器的Motion为attack1/at2/attack3（来源Standing Melee系列FBX），自动接线应从真实状态读取Motion，不能只按长FBX/状态名搜片段。新槽speed1且无退出过渡，避免旧speed2/过渡影响窗口秒数。
- **音效历史记录过期**：当前PlayerSounds/GameSoundData只剩k与空项，不再是38条完整音效。生成独立ComboDemoSounds，使用已有文件并追加引用；主场景两个SoundManager均补库，避免Awake胜出的入口缺少条目，原库保留。
- **动画事件内立刻检测会早于根位移**：事件只开关标记，在LateUpdate按实际动画时间裁剪该帧合法路径，接收MovePosition/MoveRotation目标姿态；否则高速前冲与短窗口可能采样旧位置。
- **UnityTest域重载会重放UnitySetUp**：进入Play后不能再调用EditorSceneManager.NewScene；使用Application.isPlaying门控。隔离测试需激活Animator并等待初始化后RequestReload，不能向未激活对象先Assign（运行期Assign会尝试重载而非直接写字段）。最终34项通过，包含主场景自然初始化。
- **死亡目标的碰撞体可能立即禁用**：伤害数字位置在TakeDamage之前缓存，避免死亡后读取空bounds导致数字跳到原点。
- **编辑器编译通过不代表Player可打包**：首次Windows构建发现UniGLTF的gltfExporter调用AnimationExporter的GetAnimationClips/Export，但这些方法只在UNITY_EDITOR编译，出现CS0117。给调用方的收集方法和ExportAnimations方法体补相同条件编译；保留公开入口及运行中动画导入/播放，不升级插件或改meta。修复后的Player构建结果以验收说明为准。
- **连招窗口动画/名称/伤害置灰**：临时SO草稿使用HideAndDontSave，其中包含NotEditable；PropertyField因此禁用，而手绘FloatField仍可改。改为HideInHierarchy | DontSave，BindDraft也修复已存在的草稿，保留未保存值。三个正式程序集及新增两项测试代码编译通过；编辑器正在打开本项目，本轮未运行批量测试。详情见验收说明第10节。
- **攻击比旧版慢**：旧攻击状态Speed=2，而配置连招专用槽固定Speed=1。新增逐段倍速及ComboSpeedA/B，各槽独立避免过渡中改变上一段速度；演示资产r3为2倍。原动画秒数无需再次缩短，事件、normalizedTime及根位移随播放推进。
- **Run偏左反馈不能直接等同于物理根位移偏左**：现有走跑代码已忽略动画deltaPosition/deltaRotation，主场景Animator和Rigidbody同根，直接转Animator会转物理对象。新增Humanoid姿态校正，以及键盘/相机输入补强与红绿蓝方向线；实际路线偏移的根因及现象是否消失仍待现场测量。没有宣称已实测修好。

- **只验证脸部遗漏骨盆余偏**：用户提供更新后Play持续走跑截图，补采样确认脸部对齐后当前Run骨盆仍可左偏约28度。改为Hips独立对齐、Spine补剩余旋转；192次包含骨盆/脸部/混合/微调的采样通过，物理根不变。该方法减小原腰部扭转，持续Play观感及接攻击是否跳姿态仍待验收。此前64次记录不能证明下身朝向已修好。
- **整体移动颤动与更新时机**：用户确认整个人物移动不平滑；Normal动画写MovePosition、FixedUpdate转向及Update地面修正混用节奏。方案A改AnimatePhysics并逐物理步检测地面，同时限制Run姿态补偿每次新求值只执行一次。物理动画在Update前求值，原LateUpdate命中可能被Update收招清理抢先清空，因此同步改为根位移目标计算后逐动画步采样。编译通过，现场抖动与战斗仍待复测。

## 2026-10-03 Web 光盘菜单

- **只检查中央盘漏掉侧盘裁切**：轮盘使用 overflow:hidden，侧盘的旋转、近侧深度放大和纵向轨迹会超出容器。修订改为按透视投影后的四角约束位置/缩放，并预留悬停及阴影空间；检查需覆盖侧盘与动画中间姿态。
- **透明的 3D 轨迹容器挡住鼠标**：preserve-3d 容器本身的命中平面挡住位于其后方的光盘区域，出现看得到但悬停不生效。隔离浏览器对比确认后，将 disc-track 设为 pointer-events:none，可见 disc 显式设为 auto；倾斜的 disc-face 也不参与命中。
- **快速反向切换留下半透明文字**：文字退场未完成就回到原项时，取消 Tween 后没有恢复原值。相同已显示项重新成为目标时，需要恢复 alpha=1 与 y=0，避免停留在退出中间态。
