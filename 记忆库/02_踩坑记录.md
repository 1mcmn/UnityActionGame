# 02 踩坑记录

> 报错/问题 + 根因 + 解法。新坑追加末尾，带日期。

## 2026-08-21
- **WAV 头"损坏"虚惊**：`writer.Write("RIFF".ToCharArray())` 其实没问题（BinaryWriter 默认 UTF-8，ASCII 字符=单字节），实测头部字节完全正确；但建议换 `Encoding.ASCII.GetBytes()` 做防御性写法
- **asmdef 不能引用预定义程序集**：测试 asmdef 写 `"references": ["Assembly-CSharp"]` 会静默失败（CS0246 找不到类型）→ 给 Assets/Scripts 建 `Game.asmdef`，测试引用 `"Game"`
- **asmdef 必须显式引用包程序集**：建 asmdef 后 TMPro/ugui 报 CS0246 → `Game.asmdef` 加 `"Unity.TextMeshPro"` 和 `"UnityEngine.UI"`
- **CS0104 Object 歧义**：同时 `using System;` + `using UnityEngine;` 时裸写 `Object` 报歧义 → 全限定 `UnityEngine.Object.DestroyImmediate()`
- **团结引擎 GUID 双格式**：`.meta` 里是 base64（如 `DysZvHik...=`），预制体/场景里是 32 位 hex——无法用脚本直接映射，分析依赖时注意
- **敌人 CrossFade 全失败**：EnemyAI 引用 `Goblin_Ani_*` 约 25 个名字，Monsterctrol.controller 只有 9 个状态且一半没绑动画（m_Motion 空）；素材只有 7 个 FBX 动画（其中攻击只有 Mutant Punch 一个）→ 代码按"理想动画集"写的，需对齐素材（见 04 下一步）
- **音效找不到 atk01_swing/hit**：不是 ID 缺失（PlayerSounds.asset 有 38 条全绑好），是场景里 SoundManager 的 Libraries 挂的是空的 GameSoundData.asset → 换成 PlayerSounds.asset
- **`dsh web` 报 cannot resolve profile bundle**：profile node_modules 依赖失联（装插件时 pnpm 动过依赖树）→ `dsh plugin --profile web install`（不带包名=全部重装）
- **docker pull 报 npipe 找不到**：Docker CLI 装了但 Docker Desktop 没启动 → 启动应用 / 重启（WSL 缺失时先装 WSL）
- **`wsl --install` 报 403**：网络层拦截微软下载端点（非代理问题）→ 环境墙，暂停 OpenViking
- **`bash <(curl ...)` 报"系统找不到指定的文件"**：在 cmd 里跑 bash 命令不行，`<( )` 是 bash 语法 → 必须打开 Git Bash 里跑
- **compile_check.bat 超时**：Unity 编辑器开着时会锁编译输出文件 → 跑编译检查前先关编辑器
- **CS0108 Myobject.name 隐藏基类成员**：练习脚本字段命名问题，警告不影响运行，答辩前处理

## 2026-08-22
- **格挡后泄力动画不出现**：根因是磁盘上 3 个角色 controller（Player_NewAnimCtrl / ainbe / Anbi）都没有 `Deflect`、`Blocking`、`Knockdown`、`GetUp` 参数，代码 SetTrigger/SetBool 全部空转（Console 打 "Parameter does not exist"）。用户截图里"有"但磁盘没有 → 未保存或改错控制器，未定论
- **泄力 = 攻击倒放（纯代码实现）**：`animator.Play(攻击状态hash, 0, 收尾进度) + animator.speed = 负值` 即倒放，结束恢复 speed=1 再 CrossFade 回进入前状态。**最终倒放倍速 = 状态自身 Speed × animator.speed**（攻击状态 Speed=2，speed=-1 即 2 倍速倒放）；起始进度必须小于该状态所有 Exit Time 阈值，否则被 Exit Time 抢走；切受击/倒地/死亡前必须 CancelDeflect 恢复 speed=1
- **Unity 动画倒放**：状态 Speed 填负数即倒放（动画机方案）；负速度 + Has Exit Time 有已知 bug（speed multiplier ignores exit time），退出用代码计时器兜底更稳
- **武器资源已有**：`Assets/Imports/PurePoly/Free Fantasy RPG Weapons`（单手剑 PP_Theme_11_Sword_One-Handed_003 等 26 个 prefab，自带 MeshCollider），玩家/怪物武器不用外部找

## 2026-09-19
- **`run_editmode_tests.bat` 长期静默失效**：命令行同时给 `-runTests` 和 `-quit`，编辑器加载完脚本就退出（日志里只有 CompileScripts → Application.Shutdown，零测试输出），结果只打印 "[FAIL] No result file generated"。**解法：去掉 `-quit`**——测试跑完 TestRunner 会自己退编辑器（对照实验：加 -quit 无 xml，去掉后正常产出 `EditMode-results.xml`）。教训：批处理"没有结果文件"不等于"测试通过"，那行 FAIL 一直没人当回事 → 测试红了两周没人知道
- **EditMode 套件实际状态（2026-09-19 首次真跑）**：total=219 / passed=194 / **failed=25**。其中 22 个失败来自第三方包自带测试（UniGLTF / VRM / VRMShaders 的 Texture/Import/Export 测试，非我方代码，`-runTests` 会把全工程测试都跑），我方只有 3 个失败且都是**测试过期**（不是代码回归）：
  - `ComboDataTests.Defaults_AreSane`：断言 comboWindowPercent=0.55，现默认值已改为 **0.35**（`ComboData.cs:17`，与 `PlayerCombat.cs:25` 内联回退一致）→ 改测试期望
  - `PlayerCombatTests.ComboFlow_BufferBeforeWindow_IsHeldThenConsumed`、`ComboFlow_AttackEnded_BufferIsDiscarded`：测试假设"窗口判定在 `ConsumeBufferedCombo()` 内部"，但窗口已移到状态机（`ThirdPersonController.cs:514` 用 `animCtrl.GetNormalizedTime01() >= combat.ComboWindowStart` 判断后才 `BufferCombo()`），且新增了 0.15s 残响窗口（`PlayerCombat.cs:129-130`，攻击结束后仍可续招）→ 两个测试按旧设计写，需按现设计重写
  - 想让第三方测试不参与：`-runTests` 配 `-assemblyNames Game`（或给测试 asmdef 加分类）——待定
- **顿帧 `timeScale` 无引用计数（旧账，技能系统放大）**：`SkillManager.HitStopRoutine` 和 `PlayerCombat.HitStopRoutine` 都是"存 normal → 设 timeScale → 恢复 normal"。技能系统里 `HitFeedbackComponent` 对**每个命中目标各调一次** `RunHitStop`，同帧砍中 2 个以上敌人时后启动的协程捕获到的 normal 已是 0.1，最后结束的协程把它"恢复"成 0.1 → **游戏永久 10% 速度**。解法：改成引用计数/只让第一个协程真正改 timeScale，或统一收进一个 HitStop 服务
- **音效前缀多带下划线 → 永远播不出**：`SoundManager.PlayByPrefix` 的匹配是 `key.StartsWith(prefix + "_")`，而 `HitFeedbackComponent` 默认填的是 `"hit_"` → 实际找 `hit__`，兜底精确查 `hit_` 也没有 → 每次命中打 warning 且无声。库里是 `hit_01..07`，正确写法是前缀传 `"hit"`（不带下划线）。`block_`/`parry_` 库里根本不存在，格挡/弹反音效仍需补素材


## 2026-09-22
- **技能播完/被打断后角色卡死在技能动画里**：根因两条——① 技能播的状态 `AT1` 在 `Player_NewAnimCtrl.controller` 里 `m_Transitions: []`（死胡同；对比 at2/at3/at4/Locomotion/Idle 都有出口过渡）；② `PlayAnimationComponent.OnEnd / OnInterrupt` 是空实现，技能结束时没人把 Animator 切回去，而玩家状态机靠设参数（Movement/Run/Trigger）驱动动画，停在 `AT1` 上时按键也救不回来。**解法（事件通信，方案 C）**：新增 `SkillEvents.AnimationReturnRequested`，`PlayAnimationComponent` 新增 `returnStateName` 字段并在 OnEnd/OnInterrupt 抛事件；`PlayerAnimController` 订阅后调用 `ReturnToLocomotion()`（留空则按 `Movement` 参数自动选 Idle 或 Locomotion）。详情见根目录 `错误记录.md` 的 BUG-001
- **经验**：动画机里"后加的状态"最容易漏连出口过渡；代码 CrossFade 进去之后没有过渡就是死胡同。以后新增技能/动作状态，先检查该状态的 `m_Transitions` 是否为空
- **怪物"隔空"打中玩家（BUG-002）**：`EnemyAI` 全用中心点距离判定，伤害判定是 `_attackRadius × 0.8 = 1.44m`，而两边碰撞体水平半径合计只有 0.71m → 表面还差 0.73m 就能挨打。**解法**：伤害判定改成按碰撞体表面距离（`中心距 − 自己半径 − 对方半径 ≤ 容差`），新增 `_useSurfaceHitCheck`、`_hitSurfaceTolerance`（默认 0.2m）两个可调项
- **角色"挥空也能打中怪物"（BUG-003）**：`PlayerCombat.PerformHitDetection` 原来是角色中心大球（球心身前 1.5m、半径 2.5m），刀没挥到也判定命中。**解法**：改成"武器判定胶囊 + 帧间扫掠"——胶囊优先直接读**武器上自己摆的 CapsuleCollider**（center/radius/height/direction 换算到世界空间，所见即判定体积，也正好对上任务书"命中检测使用 Capsule Collider"）；没放碰撞体时按武器网格包围盒自动拟合（最长轴=刀身方向）；再不行用节点前向兜底。三种来源在 Scene 里分别显示 🟢绿 / 🟠橙 / 🟡黄。扫掠仍用 `SphereCastAll(上一帧胶囊中心→这一帧)` 治高速挥砍漏判。**踩坑**：第一版用"节点前向 + 固定刃长"，因为武器是运行时由 `WeaponAttachment` 挂到手上的、节点朝向与刀身不一致，胶囊歪到武器两侧 → 必须按碰撞体/网格来。详细记录见根目录 `错误记录.md`
