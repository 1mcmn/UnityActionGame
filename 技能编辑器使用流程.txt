技能编辑器 · 使用流程说明书
（搞不清"音效编辑器 / 技能编辑器 / 游戏"三者关系时看这份）
================================================================

----------------------------------------------------------------
【一】先把"四个零件"认清楚
----------------------------------------------------------------
1) 音效库  SoundLibrary.asset        —— 相当于"字典"
   Assets/Scripts/Audio/PlayerSounds.asset
   内容：一张表，每行是  soundID(字符串)  →  AudioClip(音频文件)
   例：  atk01_swing  →  安比攻击1.wav
   注意：它只管"ID 对应哪个文件"，不管什么时候播。

2) 动画机  Animator Controller (.controller)  —— 相当于"演员表"
   Assets/Imports/momo/Player_NewAnimCtrl.controller
   内容：一堆 state（状态），每个 state 有自己的 **名字** 和 绑定的动画 clip
   例：  state 名叫 "AT1"  →  绑着 clip "Standing Melee Attack Horizontal"
   **技能编辑器里填的 stateName，必须是这里的"状态名字"，不是 clip 名字。**

3) 技能配置  SkillConfig.asset       —— 相当于"剧本"
   Assets/SkillSystem/Skills/NewSkill 2.asset
   内容：一个技能 = 一串组件，按顺序执行
     - PlayAnimationComponent：播哪个状态(stateName) + 技能总时长(duration) + 帧事件表
     - HitWindowComponent：第 5~15 帧检测敌人，命中就调下面两个
     - DamageComponent：伤害数值
     - HitFeedbackComponent：命中音效前缀 + 顿帧
   **帧事件（第几帧响什么音效）就存在 PlayAnimationComponent 里。**

4) 技能库  SkillLibrary.asset        —— 相当于"目录"
   Assets/SkillSystem/SkillLibrary.asset
   内容：一个 List，列出"游戏里能通过 ID 找到的技能"
   **技能资产建好了还必须加进这个列表，否则 PlaySkill 找不到它。**
   （技能编辑器左栏显示的就是这个列表）

运行时谁在用它们：
   按 J → TestSkillLauncher → SkillManager.PlaySkill("player_uppercut")
        → 从 SkillLibrary 按 ID 找到 SkillConfig（剧本）
        → 按顺序跑组件：播动画 → 到帧响音效 → 判定窗口内打伤害
   音效那一刻 → SoundManager.Play(soundID) → 从它挂的音效库里查 ID → 播 AudioClip


----------------------------------------------------------------
【二】完整操作流程（从零配一个技能）
----------------------------------------------------------------
■ Step 0  前提检查（每次开工先看这三行，能省掉 80% 的坑）
   [ ] 场景里主角根物体 tag = Player，且挂着 Animator
   [ ] 场景里有一个 SoundManager，它的 Libraries 数组里挂的是你要用的那个音效库
       （这一点最容易漏：编辑器试听用的是"全项目的音效库"，运行时只用"这里挂的"）
   [ ] 技能编辑器菜单 Tools/技能编辑器 能打开，左栏能看到你的技能

■ Step 1  音频文件 → 音效库（用"音效条目管理器"）
   1. 打开音频工具，操作目标选 PlayerSounds.asset（不要选到别的练习资产）
   2. 逐条添加： soundID 起名 → 拖入 AudioClip
      命名建议（项目约定）：攻击 atk01_swing / atk01_hit，脚步 foot_step_01...
   3. 保存。改完回技能编辑器点「刷新音效ID」

■ Step 2  场景里的 SoundManager 挂上这个库  ← 最容易忘的一步
   Hierarchy → 找到挂 SoundManager 的物体 → Inspector → Libraries
   把 PlayerSounds.asset 拖进去（数组里加一项）
   验证：进 Play，Console 应该打
        [SoundManager] 字典构建完成，共 N 条音效
        N 必须等于你库里实际有效的条数；N=1 说明库是空的或挂错了

■ Step 3  动画机里确认"状态名"
   双击 Player_NewAnimCtrl.controller → 看 Attack 那一层里每个 state 的名字
   把名字抄下来（例：AT1 / at2 / at3 / at4）

■ Step 4  技能编辑器里配技能
   1. 左栏选中技能（不在列表里就点 + 新建，或确认 SkillManager.library 挂的是哪个库）
   2. 组件列表点 + → 添加「播放动画」
   3. 填三个关键字段：
        stateName  ← 抄 Step 3 的状态名（写错 = 按 J 动作不变）
        crossFade  ← 0.1 一般够用
        duration   ← **技能总时长（秒）**，整个技能跑这么久就结束
                     ⚠ 这个值决定了"帧能走到多少"（见第四节）
   4. 组件列表点 + → 添加「判定窗口」，填 startFrame / endFrame
   5. 组件列表点 + → 添加「伤害」，填 damage
   6. 组件列表点 + → 添加「命中反馈」，填音效前缀 + 顿帧
   7. 面板下方会显示 stateName 校验结果：
        绿色 = 名字对，并告诉你 clip 名 / 帧率 / Speed / 最多能到第几帧
        红色 = 名字错，会列出所有可用状态名
   8. 点「用它做预览动画」→ 预览 clip 自动对齐运行时那个动画
   9. 拖时间轴 / 点 ▶ 播放，看着帧号配帧事件：
        拖到目标帧 → 点「在第 N 帧添加事件」→ 用 ▾ 选 soundID
        （勾着「试听帧事件」的话，播放头跨过事件帧会直接响，不用进游戏）
  10. 点左下角「保存所有修改」

■ Step 5  进游戏验证
   按 J → 看动画有没有变 → 听音效 → Console 对照第五节表格


----------------------------------------------------------------
【三】三个"坐标系"不要搞混（这是最容易乱的）
----------------------------------------------------------------
 - 音频没有帧。音效只认"什么时候被 Play 一次"。
 - **帧号是"某个动画 clip 的帧"**：第 10 帧 = 0.333 秒（30fps 时）。
   同一个"第 10 帧"，在不同帧率的动画里对应的时间不一样。
 - 技能编辑器里预览的动画，**必须和运行时那个状态绑的是同一个动画**。
   不一致 → 你在编辑器里配的帧号，游戏里就落在别的时间点。
   （现在有了「用它做预览动画」按钮，点一下就不会错）


----------------------------------------------------------------
【四】帧号能走到哪：四个数字一起决定
----------------------------------------------------------------
   最大帧号 ≈ min(duration, clip长度 ÷ Speed) × 帧率 × Speed

   实际就是：  duration(秒) × clip帧率 × 状态Speed

   举例（30fps 的 clip）：
     duration=0.5s, Speed=1  →  最多到第 15 帧
       配第 27 帧 → **永远不会触发**（而且游戏里不报任何错！）
     duration=1.5s, Speed=1  →  最多到第 45 帧
     duration=1.5s, Speed=2  →  最多到第 90 帧（Speed 让它跑两倍快）

   ★ 技能编辑器现在会直接报红：
     "这些帧事件永远不会触发：第 27、50 帧。
      duration=0.5s × Speed=1 × 30fps → 最多只能走到第 15 帧。"
     看到这行红字，就改 duration 或改帧号。

【五】出问题时的症状 → 定位表
----------------------------------------------------------------
| 症状 | 去哪儿看 | 说明 |
|---|---|---|
| 按 J 动作没变，还是原来那个动作 | 技能编辑器 stateName 校验 | stateName 写错/状态没绑动画。Console 会打 "State 'xxx' does not exist" |
| 按 J 完全没反应、Console 什么都不打 | Hierarchy 有没有 SkillManager / TestSkillLauncher | 组件没挂到场景 |
| Console: [SkillManager] 查找不到组件 | 技能编辑器左栏 | 技能 ID 不在 SkillLibrary 里（资产建了但没加进目录） |
| Console: [SkillManager] 没有查找到library | SkillManager 的 library 槽 | 没挂 SkillLibrary.asset |
| 动画有、伤害有，就是没音效 | 技能编辑器帧事件红字 | 帧号超出 duration（第四节） |
| 帧号没超但还是没音效 | Console: [SoundManager] 未找到音效: xxx | 运行时字典里没这个 ID → 库没挂/ID 拼错 |
| Console: [SoundManager] 字典构建完成，共 1 条 | 音效库资产 | 库是空的，或挂了空库 |
| 编辑器能试听、游戏没声音 | 技能编辑器「运行时校验」 | 编辑器扫全项目库，运行时只认场景挂的库 |
| Console: 未找到前缀为 xxx_ 的音效 | 音效库 | 前缀机制：PlayByPrefix("hit_") 会找 hit__01 之类；库里没这个前缀的音效 |
| 技能播一半被打断 | Console [Skill] Running->Interrupted | PlaySkill 会先打断同 ID 的旧实例，连按 J 会互相打断 |

----------------------------------------------------------------
【六】本次踩到的两个坑（记进论文"实现与测试"正好）
----------------------------------------------------------------
1) 帧号配在 27 / 50，但技能 duration 只有 0.5 秒（30fps 下最多到第 15 帧）
   → 帧事件静默不触发。判定窗口 5~15 却能打中，所以"有伤害没音效"。
   → 修法：编辑器把"最多能走到第几帧"算出来并报红（已实现）。
   根因反思：预览时拖的那条时间轴属于"另一个 clip"，帧号和运行时对不上。

2) 音效库资产里只有 1 条 soundID（k），而素材文件夹里有 22 个 wav 没入库
   → 所有 gameplay 音效（atk01_swing / hit_ / foot_step_）全都查不到。
   → 修法：用音效条目管理器把这批 wav 录进库并起 ID。**属于数据工作，不是代码。**
