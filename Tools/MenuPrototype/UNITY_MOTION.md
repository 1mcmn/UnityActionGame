# 光盘菜单交互与 Unity 移植依据

本轮按用户选择的方案 A 修改独立 Web 原型。这里记录已采用的状态、分层和参数，供后续移植到当前团结引擎 1.9.2 / Unity 2022.3 内核时复用；本轮没有修改 Unity 菜单或真实游戏存档。

## 存档流程

首次没有预设记录，只有一张新建光盘。新建入口常驻页面右上方，也可以浏览到新建光盘后使用下方按钮。

点击新建 → 名称弹窗 → 创建 → 增加独立光盘并选中。取消和 Escape 不创建记录。名称为去掉首尾空白后的 1～24 个字符。Web 的名称、ID、封面主题、创建时间使用 `interblade-menu-saves-v1` 保存于当前浏览器；Unity 端需要接入实际 SaveRepository 和游戏进度，不能把浏览器存储当作客户端存档。

已创建光盘的章节为初始战场，游戏时间与进度均从零开始。Continue 仍进入明确标注的 Web 演示完成页。

## 分层与事件

| 层 | 职责 | 触发 |
|---|---|---|
| DiscRoot / 轮盘定位 | 沿空间弧线移动、基础倾角、深度、远近大小 | 滚轮、方向键、箭头、拖动、点击侧盘 |
| TiltPivot / 美术表面 | 鼠标附近轻微倾斜，离开后回正 | PointerEnter / Move / Exit |
| 独立命中区域 | 位置跟随 DiscRoot，避免表面倾斜改变命中结果 | Pointer 与键盘确认 |
| ConfirmInk / 参考描线 | 三条细椭圆曲线依次绘制、停留、消退 | 明确确认，等待光盘定位完成后播放 |
| DetailPanel / 文字 | 旧文字退场，新标题、章节和统计错峰入场 | 当前浏览项变化 |

浏览项变化和确认是两个事件。滚轮浏览不播放确认实线。确认实线位于独立前景 UI 层，定位完成时播放一次；不作为光盘子节点，不随悬停倾斜，新的浏览事件立即收起它。键盘焦点提示与漫画确认反馈分开。

用户要求选中描线照原视频还原。已重新核对 5.83 秒参考中 3.45～4.35 秒的反馈：细而略不规则的椭圆曲线沿盘缘逐步展开，没有折角括号和荧光短线。当前确认层在播放时采样盘缘的透视投影，生成三条平滑、略不规则的开口曲线；删除之前的折线、强调色射线与缩放弹出。路径在确认时固定，缩放窗口或切换光盘立即取消。

快速连续输入会取消旧缓动，从当前位置开始追向最新目标；旧文字与确认回调不能再覆盖最新选择。减少动态效果时即时切换、取消悬停倾斜，保留确认的静态短时提示。

## 统一动画参数

实际参数来源：`src/motion.js`。

| 动作 | 时间 | Web 缓动 | 当前已安装 PrimeTween 的对应方式 |
|---|---|---|---|
| 轮盘定位 | 0.78 秒 | power3.out | Ease.OutQuart |
| 悬停与回正 | 0.28 秒 | power2.out | Ease.OutCubic |
| 细曲线描绘 | 0.56 秒，每条间隔 0.13 秒 | none / 匀速描绘 | Ease.Linear |
| 曲线停留 / 消退 | 0.24 / 0.18 秒 | 消退 power2.in | Ease.InCubic |
| 旧文字退场 | 0.12 秒，每项间隔 0.018 秒 | power2.in | Ease.InCubic |
| 新文字入场 | 0.38 秒，每项间隔 0.045 秒 | power3.out | Ease.OutQuart |

悬停最大 X / Y 倾角为 5° / 6°，表面轻微前移 8 个 Web 像素单位。文字入场位移 16 像素；依据浏览方向决定正负。滚轮累计阈值 24 像素单位、事件间隔 170 毫秒。

曲线定义：OutQuart 为 `1-(1-t)^4`，OutCubic 为 `1-(1-t)^3`。盘缘使用连续三次贝塞尔曲线，仅给半径约 1 像素的小幅不规则变化；描绘进度按路径长度匀速推进，避免变成多边形或跳动的随机噪声。

## 轨迹、投影与边界

光盘使用实际记录索引减去连续的定位进度得到 offset。桌面角间距 0.63 弧度；紧凑布局为 0.77。基础位置使用 sin / cos 生成斜向空间弧线：左侧较低、较远，右侧较高、较近。超过可见范围的盘先淡出，避免整排盘挤在一起。首尾浏览保留回绕，末项回到首项时沿该有限弧线返回，不复制或虚构额外存档。

不能只按未旋转的直径判断裁切。Web 对旋转、缩放、深度之后的四角做透视投影，再预留 18～24 像素给悬停、边缘和阴影，调整位置与必要的整体缩放。显示中的盘、侧盘和移动中的中间姿态都要验收。遮挡属于前后层次；容器产生的平直裁切不属于该效果。

后续 Unity 建议用透视 MenuCamera 渲染真正有中心孔的光盘环形网格，DiscRoot 管轨迹，TiltPivot 管表面反应；文字和 ConfirmInk 由独立 uGUI Canvas 呈现。菜单可视区决定布局范围，透视相机投影和 `WorldToScreenPoint` 决定实际边界。CSS 的 y 向下、正 z 朝向观察者；Unity 端须按菜单相机坐标转换并实测，不能直接照抄正负号。

PrimeTween 1.4.11 已在当前工程中安装。菜单动画使用 unscaled time；同一属性只允许一个有效 Tween，新的目标取消旧实例。不要通过修改全局 Time.timeScale 来模拟菜单缓动。场景隐藏或销毁时，清理 Tween、指针状态和待触发回调。

正式移植前仍需按 AGENTS.md 比较并选择 Unity 实施方案。引擎资源和 .meta 由引擎生成，不改变战斗 Root Motion 和现有存档依赖。
